# Dictionary Assets and Licences

BookBites does not include a production dictionary dump.

- BookBites source remains under the repository's existing licence.
- Limmud application source is MIT; no source was copied.
- User-imported Limmud packs may contain Wiktionary-derived Kaikki data under
  CC BY-SA and GFDL and optional Open English WordNet under CC BY 4.0.
- Each compatible pack must include non-empty source, licence, attribution,
  and homepage metadata. BookBites displays these fields.
- `mdict_flutter` is BSD-3-Clause and `dict_reader` is MIT, but neither package
  is included in this milestone.
- Readest is AGPL-3.0 and was used only as a behavioral reference.

Users are responsible for ensuring they may use and redistribute imported
dictionary data. Removing a source removes its application-managed pack, not
saved vocabulary snapshots.
